# Подключение Looksy к сайту на Tilda

Эта инструкция относится к текущему русскому production SDK:

```text
https://loosy-widget.online/min-script.js
```

SDK поддерживает стандартные карточки товаров Tilda Store (`T-store` и `T-catalog`). В большинстве случаев достаточно один раз подключить скрипт ко всему сайту: SDK сам отслеживает открытие карточки товара, находит название, цену и фотографию, а затем добавляет кнопку «Примерить на себе».

## Что понадобится

- токен магазина Looksy;
- доступ к настройкам сайта Tilda;
- опубликованный каталог с фотографиями товаров.

Токен нужно подставить вместо `YOUR_SHOP_TOKEN` в примерах ниже.

## Вариант 1. Подключение ко всему сайту

Это рекомендуемый вариант для интернет-магазина.

### Шаг 1. Откройте поле для HTML-кода

1. Войдите в Tilda и откройте нужный проект.
2. Перейдите в **Настройки сайта**.
3. Откройте раздел **Ещё**.
4. Найдите поле **HTML-код для вставки внутрь head**.

Актуальное расположение этого поля также описано в [официальной инструкции Tilda](https://help-ru.tilda.cc/html).

### Шаг 2. Добавьте SDK

Вставьте production-код:

```html
<script
  defer
  src="https://loosy-widget.online/min-script.js"
  data-shop-token="YOUR_SHOP_TOKEN"
></script>
```

Важно:

- замените `YOUR_SHOP_TOKEN` на выданный токен магазина;
- не удаляйте `defer`;
- не подключайте SDK второй раз через блок T123, Google Tag Manager или другой код.

### Шаг 3. Сохраните и опубликуйте сайт

1. Сохраните изменения в настройках сайта.
2. Переопубликуйте страницы каталога.
3. Откройте именно опубликованный сайт, а не только редактор или предпросмотр Tilda.

### Шаг 4. Проверьте карточку товара

Откройте каталог, затем откройте карточку товара.

Ожидаемый результат:

- кнопка «Примерить на себе» появляется у фотографии товара;
- при нажатии открывается виджет Looksy.

## Вариант 2. Подключение только на отдельных страницах

Если SDK нужен не на всём сайте:

1. Откройте нужную страницу в редакторе Tilda.
2. Добавьте блок **T123 «HTML-код»** из категории **Другое**.
3. Разместите его ближе к концу страницы.
4. Вставьте в него тот же тег `<script>` из инструкции выше.
5. Опубликуйте страницу.

Код из блока T123 работает только на опубликованной странице. Не используйте этот вариант одновременно с глобальным подключением в настройках сайта.

## Стандартная карточка Tilda Store

Для стандартных блоков магазина ручные атрибуты `data-fitting-*` обычно не нужны. SDK умеет находить открытые карточки Tilda Store и реагирует на их динамическое появление.

Если кнопка должна оставаться поверх фотографии, дополнительный код не требуется.

## Кнопка отдельно от фотографии: slot

По умолчанию SDK размещает кнопку поверх фотографии. Для кастомной товарной разметки можно указать другое место с помощью пустого slot:

```html
<div
  class="looksy-product"
  data-fitting-product
  data-fitting-name="Название товара"
  data-fitting-price="2990 ₽"
>
  <img
    src="https://example.com/product.jpg"
    alt="Название товара"
    data-fitting-image
  />

  <div class="looksy-product-actions">
    <button type="button">В корзину</button>

    <div
      class="looksy-fitting-slot"
      data-fitting-button-slot
      data-fitting-full-width="true"
    ></div>
  </div>
</div>
```

Slot — это не собственная кнопка, а пустое место для кнопки Looksy. SDK сам создаёт кнопку, добавляет обработчик нажатия и переносит её внутрь slot.

- `data-fitting-button-slot` указывает место для кнопки;
- `data-fitting-full-width="true"` растягивает кнопку на ширину slot;
- без `data-fitting-full-width` кнопка сохраняет обычную ширину;
- slot должен находиться внутри контейнера конкретного товара;
- для каждого товара нужен свой slot;
- если slot не найден, SDK использует стандартное размещение поверх фотографии.

Допустимы также сокращённые варианты:

```html
<div data-fitting-button-slot></div>
<div data-fitting-button-slot data-fitting-full-width></div>
```

Для отступа можно стилизовать сам slot:

```html
<style>
  .looksy-fitting-slot {
    margin-top: 12px;
  }
</style>
```

### Slot в стандартной карточке Tilda Store

Обычный блок T123 внизу страницы не является частью конкретной карточки товара, поэтому помещать в него один глобальный `data-fitting-button-slot` нельзя: SDK не сможет надёжно связать его с товаром.

Чтобы использовать slot внутри стандартного popup Tilda Store, slot необходимо динамически вставлять в разметку открытой карточки рядом с нужной кнопкой. Селекторы у блоков Tilda различаются, поэтому такую вставку нужно настраивать под конкретный блок и проверять после публикации. Если кастомная позиция не обязательна, надёжнее оставить стандартное размещение поверх фотографии.

## Кастомный Zero Block

Если товар полностью собран в Zero Block, удобнее добавить HTML-элемент или блок T123 с общей обёрткой товара и атрибутами из примера выше.

Критично, чтобы фотография и slot находились внутри одного элемента `data-fitting-product`. Раздельные элементы Zero Block без общей HTML-обёртки SDK не сможет однозначно связать между собой.

После динамического добавления или изменения товара можно попросить SDK повторно просканировать страницу:

```html
<script>
  if (window.VirtualFitting) {
    window.VirtualFitting.init()
  }
</script>
```

## Debug-режим

Для обычной установки debug-режим не нужен. Если кнопка не появляется или
нужно посмотреть работу SDK, временно добавьте `data-debug="true"`:

```html
<script
  defer
  src="https://loosy-widget.online/min-script.js"
  data-shop-token="YOUR_SHOP_TOKEN"
  data-debug="true"
></script>
```

После диагностики удалите `data-debug="true"` и оставьте основной
production-код из шага 2. В debug-режиме SDK пишет сообщения с префиксом
`[Looksy]` в DevTools → **Console**.

## Диагностика

Если кнопка не появилась:

1. Убедитесь, что сайт и страницы каталога переопубликованы.
2. Проверьте, что открыт опубликованный домен, а не только редактор Tilda.
3. Проверьте `YOUR_SHOP_TOKEN`.
4. Убедитесь, что SDK подключён на странице только один раз.
5. Откройте DevTools → **Console** и найдите сообщения `[Looksy]`.
6. Временно добавьте `data-debug="true"` или параметр `?looksy_debug_mode=1` к адресу страницы.
7. Проверьте, что в открытой карточке есть доступная фотография товара.
8. Проверьте работу в приватном окне браузера без старого кеша.

В DevTools → **Network** запрос к `min-script.js` должен завершаться статусом `200`.
